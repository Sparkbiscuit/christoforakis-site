Filuma

A plan has to survive the day.

I built Filuma around a problem close to home: making time for the work in front of me, with ADHD planning challenges in mind.

Visit Filuma App Store

Work with the time that exists.

Scheduling. The scheduler places blocks around existing commitments and prioritizes earlier deadlines when replanning. If the remaining work cannot fit, it surfaces that constraint so the deadline or estimate can be reconsidered.

Apple Calendar integration separates importing busy time from exporting work blocks to a dedicated Filuma calendar. Each direction is optional.

Time spent and work finished are different.

Progress. A timer records effort. You decide how much of the task is complete. Work sessions are linked to their blocks so the same work is not counted twice, and unfinished effort stays in the plan.

Bring the first action closer.

Starting. The Focus card keeps the next block and an optional first step together. That step also appears in the session timer and block-start notification, so you do not have to reconstruct where to begin.

Start with something you actually need to do.

Try one task with a real deadline. Does the plan make sense? Is the next step clear? If something gets in the way, I’d like to hear about it.
